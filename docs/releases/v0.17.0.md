## Spreadsheets: LET, LAMBDA, dynamic arrays

- `LET` and `LAMBDA`: names for values inside a formula, functions made of formulas, with optional parameters (`ISOMITTED`), called at once (`LAMBDA(x,x+1)(5)`), kept in a defined name, or passed to `MAP`, `REDUCE`, `SCAN`, `BYROW`, `BYCOL`, `MAKEARRAY`. A function of the engine goes there by its name: `BYROW(rows, SUM)`. One that calls itself without end is `#NUM!`.
- **A formula that gives several values fills the cells next to it**: `=SEQUENCE(5)`, `=FILTER(…)`, `=SORT(…)`, `=UNIQUE(…)`, `=A1:A5*2`, `VSTACK`, `TAKE`, `GROUPBY`, `PIVOTBY` … as many cells as it gives now. A cell in the way makes it `#SPILL!` until the cell is cleared; typing over a value it filled does the same, and Undo gives the cell back. `A1#` is all the cells the formula of A1 fills; `@` takes the one value of a range that is the formula's own.
- Saved as Excel saves them (an array formula over the cells filled, marked dynamic in the workbook's metadata; the names of `LET` / `LAMBDA` with their `_xlpm.` prefix, `@` as `SINGLE`, `#` as `ANCHORARRAY`): dynamic again when the file is opened, here and in Excel.
- A formula read from a file that is not marked so keeps Excel's older reading (where one value goes, a range gives the one of the formula's own row or column), also when it is filled down, pasted, or put back by Undo. Only a formula typed becomes a dynamic array formula.
- A range holding a dynamic array formula is not sorted (Excel refuses too): sort the cells it reads, or use `SORT`.

## Spreadsheets: names, tables, references

- **Defined names** of the workbook, and those local to a sheet, are evaluated: `=SUM(Sales)`, `=Rate*A1`. A change in the cells a name stands for computes what uses it; the names follow rows and columns inserted or deleted. A formula with a name kept the value of the file.
- **Structured references**: `Table1[Qty]`, `Table1[@Qty]`, `[@Qty]` in a cell of the table, `Table1[[#Headers],[Qty]]`, `Table1[#All]`, `Table1[[Q1]:[Q4]]`.
- **3-D references** (`Jan:Dec!B2`) and the **intersection** of two references (a space: `B2:D4 C1:C9`, `North Q1`).
- Names and tables are read from the file: they cannot be defined or changed in the editor yet.

## For integrators

- A workbook whose formulas use defined names, tables or the functions added is computed where its values were kept: after the first edit a cell may show another value than the one the file held, if that one was stale.
- A copied cell (`ClipCell` of `xlsx.copy`) has a fifth element, `true`, when its formula is a dynamic array formula; the cells a formula fills are copied empty when their formula is copied with them. An edit result has `grown` (`{ rows, cols }`) when a formula filled cells past the last row / column of the sheet.
