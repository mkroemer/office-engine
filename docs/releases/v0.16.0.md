The second round of the QA pass over v0.14.0 (180 findings): the ones rated medium and low, and what v0.15.0 left half done. With v0.15.0 this covers all of the critical and high ones but the stretched page of a table row taller than a page in the editor (its print is fixed).

## Spreadsheets: calculation

- **A sheet where every row reads the whole table** (running totals, `COUNTIF`, `SUMIFS`, lookups down 10,000 rows) took 20 seconds to minutes per edit. Ranges are read row by row, and a block asked for twice in a pass is kept until one of its columns changes: 2 seconds where it took 20, 59 and 178.
- `TODAY()`, `NOW()`, `RAND()` and what reads them are computed when a workbook is read, as Excel does (a file showed the days overdue of the day it was saved). The document is not marked changed.
- `TEXT()` formats as cells do: exponents, fractions, conditions, `@`, `[$…]`. `;;;` and `0;;` hide values, `[$-42A]` gives Vietnamese day and month names, serial 0 and the weekdays before March 1900 are Excel's.
- Excel's rules where the engine had its own: `=0.1+0.2-0.3` is 0; `ROUND` / `ROUNDUP` / `ROUNDDOWN` / `TRUNC` with more digits than a number has; `"<>5"` leaves out the text "5"; `GCD` / `LCM` with text and empty cells; `(5)`, `Jan 15, 2024`, `15-Jan-2024`, `1 1/2` are numbers; error codes and bounds (`YEAR` past 9999, `INDEX(r,-1)`, `MID`); `CHAR` / `CODE` in Windows-1252; `DATEDIF` "yd" from the 29th of February.
- Text compares as it sorts in Excel (`đ` before `e`, `á` before `b`), not by character code.
- A cell holding an ISO date (`t="d"`) is a date to formulas. Whole columns of two sheets (`SUMPRODUCT(Data!C:C,T!A:A)`) are read to the same extent. A reference past Excel's last row works in a sheet that has the row (a large CSV).
- General shows a number in what fits the column: decimals rounded, then scientific, `###` only when not even that fits. A number of 7 digits showed as `######` in a column of the default width. What fits is measured in the font the browser draws the cell in, so a number is never wider than its cell where the sheet's font is missing.

## Spreadsheets: typing and keys

- `+A1+B1`, `-A1` and `@SUM(A1:A3)` are formulas; `#N/A` and the other error values typed are errors; `1,234,567`, `$50`, `€1,200.50` and `50 ₫` are numbers shown as typed; a number of more than 15 digits (a card number) stays as typed.
- A formula typed into a cell without a format shows as what it computes: `=TODAY()` and `=A1+30` as dates, `=A1` as A1 is shown. It showed the serial number.
- Text that does not come from a key (an IME composition, an emoji picker, a virtual keyboard) starts the edit of the selected cell. Ctrl/⌘+S while a cell is edited commits it and saves.
- Keys as in Excel: Tab, Tab, Enter comes back to the column the row was started in; Home, End, Ctrl+Home, Ctrl+End; Ctrl+Arrow stops at the edge of a block of filled cells; Shift+Space, Ctrl+Space, Alt+=, Ctrl+;, Ctrl+Enter; F4 cycles `$` on the reference at the caret.
- A fill handle at the corner of the selection. One copied value fills the selection it is pasted into; a clipboard holding only HTML pastes its table; a paste over merged cells is refused with a message instead of dropping data.
- *Duplicate sheet* copies the sheet (it made an empty one). A refused sheet name says why; merging cells that hold data says what goes.
- *Wrap text* and a text rotation grow the row; a double click on a column edge fits it to its text; a column widens when what is typed would show `####`. Pattern fills, diagonal borders, shrink to fit and rich text (parts of a cell in fonts of their own) are drawn; tilted text goes out over the cells to its right instead of being cut.
- *Custom format…* in the number formats takes a format code typed by hand (`#,##0 "đ"`, `ddd dd/mm`). At 390 px the bar wraps instead of leaving buttons off the screen.

## Spreadsheets: sorting and formats

- A sort is in Excel's order: numbers, text, FALSE, TRUE, errors, then the cells without anything, last in either direction (booleans sat among the numbers, errors among the text, and text was in "natural" order, `item2` before `item10`). Comments go with their rows. A range holding merged cells is refused, as Excel does: a value ended under a merged cell, unseen. A fill skips the cells under a merge.
- Sorting 300,000 rows took 7.6 s and 800 MB: 0.75 s. Undo of inserted / deleted rows and columns no longer copies every row of the sheet, twice (2.1 GB → 0.9 GB on that sheet).
- **A format given to a whole column stopped at row 200,001**, and made 200,000 cells to carry it (6 KB became 843 KB); the whole sheet stopped at row 19. A column or row selected by its header, or the whole sheet, takes the format as its own (`<col style>`, `<row s>`), as Excel writes it: its empty cells show it, and what is typed there later has it. A plain range too large to format cell by cell is refused with a message.

## Spreadsheets: the saved file

- Changing a column width, hiding a column, inserting or deleting rows / columns kept only width and height of `<cols>` and `<row>`: the style of a whole column or row, outline levels, and the width of hidden columns were lost.
- A note that only moved (rows inserted above it) was written as a threaded comment without its author. A sheet written again from the model wrote shared strings as plain text: rich text was lost.
- Text shaped like `_x0041_` became "A" after save and reopen, and control characters were deleted without a word: both are escaped as the format says. A formula giving text that starts with `=` keeps its value.
- **A protected sheet refuses** the edits of its locked cells and what its protection does not allow, a workbook with a locked structure the changes of its sheet list, with a message. They were edited as if nothing was said. Locked cells are not cut either.

## Spreadsheets: collaboration

- A formula typed while someone else inserted or deleted rows / columns, or renamed a sheet, kept reading the old place (`=A10*2` after a row was inserted above; `#REF!` after a rename). It is rewritten with the operation.
- Undoing one's change of a cell no longer takes away what someone else typed over it since.

## Documents

- Typing fast across a page boundary joined or reordered paragraphs (keys read a caret the view had not shown yet). After Enter at the end of a page the toolbar was disabled.
- Paste: lists from Word are lists, an HTML table is a table, a `data:` picture is a picture, a paragraph pasted after a list is not an item. Copy inside the document no longer puts list markers and a hard black color into the clipboard.
- Enter on an empty list item leaves the list (also when it comes right after the list button, before the paragraph is shown as an item). *Remove* and a new address in the link dialog act on the link the caret is in. ArrowRight leaves a table from its last cell. Find matches composed and decomposed text alike.
- Editing a paragraph keeps inline content controls (`w:sdt`), `w:customXml` and `w:smartTag` around its text, column breaks, `w:ptab`, `w:dir` / `w:bdo`, tracked format changes and moves.
- Shown as Word shows them: a nested field (the result of the outermost one; it read "Dear «Gender»Mr."), an equation in a linear form (`a/b`, `c^2`, roots, sums with limits, where the letters ran together), a footnote reference by its number, list numbers in the formats beyond decimal, Roman and letters, lists using a list style, legal numbering, even-page headers and footers.
- A part encoded in UTF-16 was a blank document. Editing a header left the comment anchored in it an orphan. A collaborator's typed word was one tracked insertion per character on the receiving side.
- A table row taller than a page was cut off in print / PDF: the page takes the height of its content and the browser breaks it. The editor still shows such a row on one stretched page.

## Presentations

- A click on a table cell edits its text; Tab moves between cells. (It selected the table, typing was swallowed, and Delete removed the whole table.)
- Adding, duplicating, deleting, moving and hiding a slide are undone and redone with the rest. A deleted slide was gone for good.
- Tab and Shift+Tab in a list item change its level; Tab typed a tab character into the file.
- Speaker notes are read and are in the text export.

## CSV, converted files, files that are not what they say

- A CSV in Windows-1258 (Excel on Vietnamese Windows) was read as Windows-1252. It is recognized by its tone marks; `encoding` in the open parameters names one.
- The columns of a CSV past 16,384 were dropped without a word: the viewer says so.
- The CSV export wrote numbers as shown (`1.23457E+11`) and text starting with `=`, `+`, `-`, `@` as it is: numbers are written whole, such text with a `'` in front (CSV injection). TSV starts with a byte order mark.
- An `.xls` / `.doc` that is HTML, CSV or text opens as what it is, a `.doc` named `.docx` is converted; a PDF, a picture, an encrypted or a damaged file is called that, where the message spoke of a "central directory".
- A package without `[Content_Types].xml` gets one when saved; a part whose checksum fails is refused when it is read.
- Booleans of `.xls` / `.ods` are booleans, not `=TRUE()`. The first page footer of a `.doc` was written as a header. Visio groups nested 50 deep and more.

## Diagrams and Markdown

- PlantUML: `actor Guest as g` showed the alias and drew a second node; one-line deployment elements (`agent`, `artifact`, `cloud`, `folder` …) were dropped; state descriptions, swimlanes, multi-line notes, `!define` / `!$var` / `!if`.
- Mermaid: markdown strings, edge labels with `|` or `--` in quotes, edge ids, `box` in sequence diagrams. DOT `strict` merges duplicate edges.
- A line that cannot be read in a Mermaid flowchart or sequence diagram, or in DOT, is an error naming the line, where a partial picture was drawn without a word.
- Markdown emphasis: a 342 KB file took 17 s to read. One pass.

## For integrators

- Open parameter `encoding` (a `TextDecoder` label) for text files; the worker emits `warning` (`{ text }`) when a file opened but not whole.
- Sheet operation `duplicate`. A cell of `xlsx.block` has a sixth element when its text is rich: the parts with their fonts (`TextRun[]`). A `format` over whole columns (`r0: 0` to the last row) or whole rows sets the column's / row's own format; over a plain range of more than two million cells it throws. Edits of a protected sheet throw with the message to show.
- Collaboration: sheet operations carry the name of their sheet, a rename the name it replaces. Every client of a room needs this version.
- `<office-viewer>` fires `load` once per document. A converted file opens clean (not dirty).
- Not done from the pass: the editor's page for a table row taller than a page, zoom in the grid, rows fitted to wrapped or turned text when a file that says no row height is opened, find in presentations, pictures linked from the web in pasted HTML, undo of slide list changes in a shared session. No new dependency.
