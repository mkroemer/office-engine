## Fixes

- Spreadsheets: formatting a workbook that came without a styles part is kept when the file is opened again. Such a workbook (the smallest valid one: a workbook and a sheet, the way a host may create a blank spreadsheet) got its styles part on the first format, but nothing in the saved file named it: no relationship from the workbook, no content type. The cells kept their style numbers and the styles were in the file, yet a reopen showed every cell unformatted: bold, colors, fills, borders, alignment, sizes, number formats. Text, merges, row heights and column widths were not affected. The saved workbook now names its styles part, as the file format asks.
- Spreadsheets: files saved that way by an earlier version open with their formatting again. Their styles part is read although no relationship names it, and the next save names it: nothing has to be repaired by hand. (In an earlier version the formatting of such a file came back on screen as soon as any cell was formatted.)
